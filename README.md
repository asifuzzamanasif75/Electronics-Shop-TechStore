# Electronics-Shop---TechStore
A responsive electronics e-commerce website built using HTML, CSS and JavaScript for the MIS 455 Midterm Practical Project.
MIS 455 Midterm Practical Website
Student: Md. Asifuzzaman
ID: 2211281

FILES
- index.html       Home page (uses display: flex)
- products.html    Products page (uses display: grid)
- contact.html     Contact Us page
- style.css        Shared styling for all three pages
- script.js        JavaScript button functions
- images/          Local Storage

NOTES
- All images are stored locally in the images folder; no internet connection is needed for them.
- Product prices and contact details are sample academic-project content.
- The contact form demonstrates front-end validation and a confirmation message. It does not send data to a real email server.

UPDATED PRODUCT FEATURES
- Products are grouped into separate Laptop and Smartphone sections.
- Each category contains three named models with product images.
- Buy Now opens a checkout form for customer name, phone number, and email.
- Explore TechStore opens the product catalogue.
- Checkout is a front-end academic demo; it does not process payments or send orders to a real server.
